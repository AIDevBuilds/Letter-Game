# Letter Game (Android)

Android prototype of a letter-tracing game.

## What it contains

- `MainActivity`: loads a letter image from the drawable resources
- `DrawingImageView`: a custom `ImageView` that draws strokes over the letter and keeps track of the drawn area
  against the letter's area

This is a small prototype, not a finished game.

## Run

Open the project in Android Studio and run the `app` module.
